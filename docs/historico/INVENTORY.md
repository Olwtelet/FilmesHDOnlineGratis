### Conventions used in docs/pages

- Each copy line is `selector [data-attrs] {flags}: text`. The selector lists **all** classes in source order (class order matters for the DOM gate).
- Text is shown after HTML whitespace collapsing. Invisible characters are made visible: `{nbsp}` = U+00A0, `{zwj}` = U+200D (Webflow “empty” rich-text paragraphs), `⏎` = a `<br>`, `␠` = a **significant** leading/trailing space inside the text node (e.g. CMS values such as `Executive Producer␠`; the DOM gate keeps it, so it must be emitted). Curly quotes `’ “ ”` and the en dash `–` are literal.
- `┄ N× identical <selector>` = N consecutive siblings with identical copy (e.g. the 7 copies of the prizes marquee list, the 22 footage items whose captions are all the same placeholder).
- `▸ <wrapper> {flag}` = a wrapper that changes visibility: `desktop-only(data-hide=mobile)`, `mobile-only(data-hide=desktop)`, `HIDDEN:w-condition-invisible`, Webflow empty state (`w-dyn-empty` inside a list, hidden by `w-dyn-hide`).
- `::after="EXPLORE"` = the `data-after` attribute, rendered by CSS `content: attr(data-after)` (the hover roll of the explore buttons).
- Rich text is shown per child block with its inline markup simplified (`<strong>`, `<a href>`, `<sub>`…).

## Quick facts for builders and testers

1. **17 routes**: 7 static pages — home (`/`), work (`/work`), about, contact and 3 legal pages sharing one layout (`data-page="policy"`) — the 404 utility page, and one CMS template (`/films/<slug>`, Webflow page `673306dca8fcb48d30953c00`, collection `673306dba8fcb48d30953be7`) for 9 films in this order: savoy, moon-in-the-12th-house, taboo, kafkas-last-trial, my-project-x, ana-maxim, outsider-freud, by-any-means, thehousewife. Every film list on the site (home roll, work slider, lightboxes, nav rows, next-film list) uses this order.
2. **Without app.js nothing is visible**: `out.css` sets `[data-taxi]{visibility:hidden;opacity:0}` and `.nav-w{opacity:0}`; app.js fades them in. On `/` and `/work` the film stills are hidden `<img>` re-drawn by WebGL.
3. **WebGL mask (now local)**: app.js loads the mask texture `6787be25e793fecfdd4a360b_all-masks.webp` that the original serves from `cdn.prod.website-files.com`; without it the home roll and work slider draw **no images at all** (verified by blocking the host). `tools/sync-assets.mjs` now downloads it to `/assets/img/site/all-masks.webp` and rewrites the URL in `public/assets/js/app.js`. Everything in the manifest (368 files, 134 MB) is present on disk.
4. **Mobile behaviour is decided by user-agent sniffing, not viewport width** (`B.isMobile`, regex on `navigator.userAgent`). Resizing a desktop browser to 375 px gives the mobile *CSS* but the desktop *JS* (drag handlers, blur, sounds, parallax). Test mobile with a mobile UA (Playwright device emulation).
5. **Non-deterministic runtime**: footage captions are hidden at random (`Math.random() < .4`), char roll-overs use random repeats/stagger; the nav's film “ticket” follows the home slider; cookies `preloader_shown` (1 h) and `tutorial_shown` (48 h) change what `/` shows. Visual comparisons must pin these (set both cookies, mask captions). The intro spin is deterministic: `/` always settles on slide 7 (**Outsider Freud**, 60 mod 9 = 6) and `/work` on slide 2 (**Moon in the 12th House**, 100 mod 9 = 1), not on the first film.
6. The DOM contains a lot of **hidden but required markup**: `w-condition-invisible` sections, `w-dyn-empty` “No items found.” blocks, 7 identical copies of each prizes list, all 9 films in every “next film” list, desktop **and** mobile copies of the same reviews/buttons, FLIP duplicates on `/work`, `<link rel="prefetch|prerender">` inside the nav and lists, URI-encoded `text/x-wf-template` scripts and lightbox JSON scripts.

## d. Interaction catalogue (what app.js and main.css do with each hook)

GSAP defaults in app.js: `duration: 1, ease: "expo.out"`. CSS easing tokens (main.css `:root`): `--easeOut: cubic-bezier(.77,0,.175,1)`, `--easeOutBack: cubic-bezier(.175,0,.77,1)`, `--easeOutQuint: cubic-bezier(.23,1,.32,1)`, `--customEase: cubic-bezier(.19,1,.22,1)`, `--panels-duration: .9s`. Lenis smooth scroll: `duration 1`, easing `t => t === 1 ? 1 : 1 - 2^(-10t)`, `smoothWheel: true`, `smoothTouch: false`, `touchMultiplier 2`. A `ResizeObserver` on `<body>` re-evaluates `B.isMobile` and sets `--100vh` on `<html>`.

### d-1 Boot order

1. `jm = [data-preloader="w"]`: if present (home only) the preloader runs, otherwise `PRELOADER_CLICKED = true` immediately.
2. `B` statics: Lenis scroll, Taxi (`al`), WebGL (`$`, canvas appended to `[data-gl="c"]`, clear colour black, DPR ≤ 2, post-processing quad with bulge/film-grain/noise shader), then `tl` (DOM modules) in a microtask; one `gsap.ticker` drives cursor, Lenis, DOM modules and WebGL.
3. `tl.create()`: `new Hn()` (menu), roll if `[data-roll='wrapper']`, slider if `[data-slider='wrapper']`, footage if `[data-footage='w']`, then for each selector in the module table below one instance per matching element.
4. Page reveal (`al.animateIn`): `[data-taxi]` `autoAlpha 0→1, 0.8 s` with delay 1.4 s (home, work — waits for preloader click **and** WebGL textures), 0 s (contact, 404), 0.6 s otherwise. Nav: logo `autoAlpha 0→1 0.8 s`, menu `yPercent -200→0 1.2 s`, delay 1.6 s (home/work) or 0.6 s.

### d-2 Page transitions (Taxi.js)

- Links: `a:not([target]):not([href^=\#]):not([data-taxi-ignore])`, same host only (mailto/tel/external fall through). Ctrl/Meta-click is not intercepted. Prefetch on `mouseenter`/`focus` of same-host links (`fetch` with header `X-Requested-With: Taxi`). Non-2xx response → full navigation to the URL.
- Leave: `[data-taxi]` `autoAlpha → 0, 0.2 s`, all DOM modules destroyed, WebGL planes removed (`alpha → 0`). Enter: `scrollTo(0, immediate)`, `P.page = view.dataset.page`, sound listeners re-bound, `animateIn()` as above, modules and WebGL rebuilt. Only the content of `[data-taxi]` is swapped (and the title); body-level elements (rotate notice, preloader, tutorial, canvas, scripts) stay from the first page loaded.

## g. Original quirks to preserve (do not “fix”)

1. **WebGL mask** (`all-masks.webp`): referenced only from app.js. On the original it comes from the Webflow CDN; blocking that host turns `/` and `/work` into black pages with only the text layer. It is now localized (`/assets/img/site/all-masks.webp`, in the manifest), so the replica works offline.
2. **Placeholder in the nav case panel**: on every non-film page `.case-menu-tx` = “This is some text inside of a div block.” (Webflow default); on film pages = synopsis + trailing space.
3. **403 placeholder image**: 3 Savoy prize items use `/assets/img/webflow/placeholder.60f9b1840c.svg` (`img.prize-it-img.w-dyn-bind-empty`), and the URI-encoded footage template of thehousewife references it too; the original URL answers 403 on the live site, the local copy came from Webflow’s cloudfront CDN.
